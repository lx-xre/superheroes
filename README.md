# 🦸 Superhéroes - CRUD en Laravel 7

Este proyecto es una aplicación web desarrollada con Laravel 7 que permite registrar, visualizar, editar y eliminar información de superhéroes. Forma parte de una actividad de práctica para aprender a manejar operaciones CRUD conectadas a una base de datos.

## 🚀 Funcionalidades

- Registrar nuevos superhéroes
- Editar información existente
- Eliminar superhéroes del registro
- Ver la lista completa de superhéroes
- Ver información detallada de un solo superhéroe

## 🛠️ Tecnologías utilizadas

- [Laravel 7](https://laravel.com/docs/7.x)
- PHP 7.x
- MySQL / phpMyAdmin
- Bootstrap 4 (vía CDN)
- XAMPP
- Composer
